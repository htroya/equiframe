# Operational validation

[Handbook](index.md) · [CI acceptance](first-acceptance-0.15.8.md) ·
[Compatibility](compatibility.md) · [Detector evaluation](cientifico.md)

- **ETL execution in CI.** Verify the completed native receipt against the
  trusted reference, contract and input snapshots. Retain the exit and report
  from the acceptance command. Exercise a valid run, a divergence, unavailable
  evidence and an interrupted load followed by a retry.
- **Installed wheel compatibility.** Identify the wheel SHA-256, platform,
  Python version, resolved engines, row counts, timings and outcome of each
  measured cell.
- **Isolation Forest.** Fit and calibrate on separate normal data. Evaluate on
  held-out groups against a stated reference and simple controls. Report added
  detections, false alarms, misses and cases without an evaluable profile.

Keep comparable evidence for each run and preserve the difference between a
failed check and missing evidence. Review release and research results within
their recorded scope.
