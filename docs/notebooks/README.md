# Cuaderno de Isolation Forest

El [cuaderno ejecutado](03_isolation_forest.ipynb) instala
`equiframe[engines,ml]==0.14.0`. Usa lotes sintéticos separados para entrenar,
calibrar y probar el detector. Muestra las puntuaciones, el umbral y el
recuento de detecciones, falsas alarmas, omisiones y casos no evaluables.
