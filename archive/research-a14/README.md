# Historical research and validation material

These files preserve the pre-consolidation Alpha core, research utilities, dated
reports and tests from public commit
[`cdd4bf53f48ee8cc267fa32acea30c377bbcfc56`](https://github.com/htroya/equiframe/tree/cdd4bf53f48ee8cc267fa32acea30c377bbcfc56).
`inventory.json` records every original path and SHA-256. Archived bytes are not
rewritten to describe a newer release.

The maintained library is at the root: start with
[`docs/index.md`](../../docs/index.md). The maintained benchmark remains at
[`packages/equiframe-benchmark`](../../packages/equiframe-benchmark).

Archived tests describe historical layouts, versions and workflows. They are not
the active root suite and are not shipped in current distributions. Reproducing
an old result requires its identified original commit, dependencies and artifacts.
Relative paths in scripts remain historical; do not execute their installation or
deployment commands against current services.

The DW, data client and portal contributions retain their original directories.
