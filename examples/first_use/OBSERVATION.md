# First use technical record

Keep this record alongside the execution output.

- Date, operating system, architecture and Python version
- Wheel and kit SHA-256, installed dependencies and source revision if applicable
- Verification, installation, execution and diagnosis elapsed times
- Commands, exit codes, comparison state and completeness
- Report path and integrity check
- Expected result, actual result and steps to reproduce a discrepancy
- Retry outcome and the identity of any updated artifact

Retain minimized evidence and keep private source data in the work directory.
