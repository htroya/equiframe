# Registro de primer uso

## Estado de aceptación

**Aceptación humana pendiente. Objetivo de cinco minutos no validado.**
Una revisión automatizada externa del artefacto es evidencia técnica separada.
No atribuya su tiempo a una persona ni rellene este formulario retrospectivamente
con supuestos. No se necesita ampliar el catálogo antes de resolver bloqueos.

## Protocolo de observación humana

Una persona que no haya implementado las recetas recibe solo el kit verificado
y esta guía. No necesita acceso al código del núcleo. Puede pedir ayuda: registre
qué ayuda recibió. Use un entorno limpio Python 3.12 y directorios nuevos.

1. Registre inicio antes de verificar/instalar; registre por separado el tiempo
   de obtención del kit y preparación previa de Python
2. Siga README hasta localizar correctamente el fallo del refactor
3. Registre hora del diagnóstico correcto, errores y ayuda; no detenga el reloj
   mientras descarga dependencias ni descarte intentos fallidos
4. Continúe migración y CI; pida explicar equivalent/different/not_evaluable,
   completitud, evidencia previa al fallo y diferencia entre acuerdo/corrección
5. Compare el primer diagnóstico con la meta de cinco minutos; informe tiempo
   total e instalación por separado, sin convertirlo en un benchmark universal
6. Si hay bloqueos, regístrelos, corríjalos y repita con la versión nueva. Preserve
   intentos anteriores y hashes; no los reescriba como aprobados
