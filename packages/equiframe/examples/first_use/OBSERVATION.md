## Human observation protocol

A person who did not implement the recipes receives only the verified kit and
this guide. Core source access is unnecessary. Help is allowed: record exactly
what help was received. Use clean Python 3.12 and new directories.

1. Record the start before verification/installation; separately record obtaining
   the kit and preparing Python beforehand
2. Follow README until the refactor failure is correctly diagnosed
3. Record the correct diagnosis time, errors and help. Do not pause the clock
   while downloading dependencies or discard unsuccessful attempts
4. Continue through migration and CI. Ask the person to explain the three states,
   completeness, evidence before failure and agreement versus correctness
5. Compare the first correct diagnosis with the five-minute target. Report total
   and installation time separately without turning one observation into a
   universal benchmark
6. Record blockers, correct them and repeat using the identified new version.
   Preserve previous attempts and hashes; do not relabel them as passed
